# dockerfile-fixtures

Template for the Dockerfile Labels bug bash. Click **Use this template**, create
`bugbash-<yourname>` in this org, and the Datadog test org will scan it automatically.

A polyglot "shop" monorepo used to exercise Dockerfile inventory scanning and image source
label pull requests. Nothing here is meant to be built or deployed. See `EXPECTED.md` for
what each file should do.
